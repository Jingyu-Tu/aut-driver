# 🚗 OpenHarmony Hi3861 智能小车系统


## 📖 项目简介

本项目是基于 **OpenHarmony 操作系统** 和 **华为海思 Hi3861** 芯片设计的 **云边协同智能小车系统**。

小车通过多种传感器感知环境信息，利用华为云IoT平台实现数据上报与远程控制，实现端-云协同的物联网应用范例。

## 🧩 系统架构

系统分为四大模块：

| 模块 | 包含内容 |
| :--- | :--- |
| **外设驱动层** | GPIO、PWM、UART、ADC、IIC |
| **传感器采集层** | OLED显示、温湿度(AHT20)、光照、超声波测距、红外循迹 |
| **电机控制层** | 双编码器、驱动电机、舵机（PID闭环控制） |
| **通信层** | Wi-Fi(MQTT) + 蓝牙 |

## 🎯 功能模块说明

### 外设驱动模块
学习并实现了 Hi3861 的以下外设驱动：
- **GPIO**：控制LED、读取红外传感器
- **PWM**：电机调速、舵机控制
- **UART**：蓝牙通信
- **ADC**：读取光照传感器模拟值
- **IIC**：驱动OLED和AHT20

### 传感器采集模块
- **OLED显示**：实时显示温湿度、光照、距离等数据
- **温湿度采集**：AHT20读取环境温湿度
- **光照采集**：ADC读取光敏电阻电压值
- **超声波测距**：HC-SR04实现避障检测
- **红外循迹**：双路红外实现黑线循迹

### 电机控制模块
- 双编码器电机实现 **速度闭环PID控制**
- 舵机控制超声波探头方向
- 支持前进、后退、左转、右转、调速

### 华为云物联网交互
- **Wi-Fi连接**：配网并连接华为云IoT平台
- **MQTT协议**：数据上报与命令下发
- **JSON解析**：解析云端下发的控制指令

### 通信模块
- 蓝牙模块实现本地调试与手机APP通信


## 🚀 快速开始

### 环境准备
本项目涉及 OpenHarmony（Hi3861）和 STM32 双平台开发，需要安装以下工具：

#### 1. 代码编辑器
| 工具 | 版本 | 用途 |
| :--- | :--- | :--- |
| **Visual Studio Code** | 最新稳定版 | 编写和编辑所有代码（C/JSON/Shell等） |

#### 2. OpenHarmony（鸿蒙）开发环境

| 工具 | 版本 | 用途 |
| :--- | :--- | :--- |
| **VMware Workstation Pro** | 16.x 或 17.x | 运行鸿蒙镜像的虚拟机平台 |
| **鸿蒙系统镜像** | OpenHarmony 3.0 / 3.2 | 预装了Hi3861编译工具链的Linux环境，用于编译鸿蒙固件 |
| **HiBurn** | 最新版 | 鸿蒙固件烧录工具，通过串口将 `.bin` 文件烧录到 Hi3861 芯片 |

#### 3. STM32 开发环境（移植程序使用）

| 工具 | 版本 | 用途 |
| :--- | :--- | :--- |
| **Keil uVision5** | MDK v5.x | STM32 程序的编辑、编译和调试（ARM开发环境） |
| **STM32 ST-LINK Utility** | 最新版 | 通过 ST-LINK 烧录器将固件下载到 STM32 芯片 |

#### 4. 串口调试与驱动

| 工具 | 版本 | 用途 |
| :--- | :--- | :--- |
| **UartAssist**（串口调试助手） | 最新版 | 调试串口通信，查看传感器数据、打印日志等 |
| **CH341SER** | 最新版 | USB转串口驱动，用于电脑识别串口设备（如Hi3861开发板、蓝牙模块等） |
