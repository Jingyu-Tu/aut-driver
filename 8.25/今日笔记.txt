一、常用命令（按功能分类）

1. pwd — 显示当前所在目录的绝对路径。

2. ls — 列出当前目录下的文件和文件夹。

3. ls -l — 以详细列表形式显示文件权限、大小、修改时间等。

4. ls -a — 显示所有文件，包括以点开头的隐藏文件。

5. cd 目录路径 — 切换到指定目录。

6. cd .. — 返回上一级目录。

7. cd ~ — 切换到当前用户的主目录。

8. cd / — 切换到系统根目录。

9. mkdir 目录名 — 在当前目录下创建新文件夹。

10. mkdir -p 父目录/子目录 — 递归创建多级目录。

11. rmdir 目录名 — 删除空目录。

12. rm 文件名 — 删除文件。

13. rm -r 目录名 — 递归删除目录及其所有内容。

14. rm -f 文件名 — 强制删除文件，不提示确认。

15. cp 源文件 目标路径 — 复制文件到指定位置。

16. cp -r 源目录 目标路径 — 递归复制整个目录。

17. mv 源 目标 — 移动文件或目录，也可用于重命名。

18. touch 文件名 — 创建空文件，或更新已有文件的时间戳。

19. cat 文件名 — 在终端中显示文件全部内容。

20. less 文件名 — 分页查看大文件内容，按 q 退出。

21. head -n 行数 文件名 — 查看文件开头若干行。

22. tail -n 行数 文件名 — 查看文件末尾若干行。

23. tail -f 文件名 — 动态跟踪文件新增内容。

24. grep "关键词" 文件名 — 在文件中搜索包含关键词的行。

25. grep -r "关键词" 目录 — 在目录下所有文件中递归搜索。

26. find 目录 -name "文件名模式" — 按名称查找文件。

27. find 目录 -type f -size +10M — 查找大于 10MB 的普通文件。

28. echo "文本" — 在终端输出文本，常用于脚本。

29. echo "文本" > 文件 — 将文本写入文件（覆盖原内容）。

30. echo "文本" >> 文件 — 将文本追加到文件末尾。

31. chmod 权限 文件 — 修改文件或目录的读写执行权限。

32. chown 用户:组 文件 — 修改文件或目录的所有者和所属组。

33. ps — 显示当前终端运行的进程。

34. ps aux — 显示系统所有进程的详细信息。

35. kill 进程ID — 终止指定进程。

36. kill -9 进程ID — 强制终止进程。

37. top — 实时查看系统资源占用和进程状态。

38. htop — 更直观的交互式进程查看器。

39. df -h — 查看磁盘分区使用情况。

40. du -sh 目录 — 查看目录总大小。

41. du -h --max-depth=1 — 查看当前目录下各子目录大小。

42. free -h — 查看内存和交换分区使用情况。

43. uname -a — 查看系统内核版本和架构信息。

44. whoami — 显示当前登录用户名。

45. hostname — 显示主机名。

46. ifconfig — 查看网络接口配置。

47. ip a — 查看网络接口和 IP 地址。

48. ping 域名或IP — 测试网络连通性。

49. wget 链接 — 下载网络文件。

50. curl 链接 — 发送 HTTP 请求并获取内容。

51. tar -czvf 压缩包名.tar.gz 目录 — 打包并压缩为 tar.gz 格式。

52. tar -xzvf 压缩包名.tar.gz — 解压 tar.gz 文件。

53. zip -r 压缩包名.zip 目录 — 压缩为 zip 格式。

54. unzip 压缩包名.zip — 解压 zip 文件。

55. history — 查看当前用户执行过的命令历史。

56. clear — 清空终端屏幕内容。

57. exit — 退出当前终端会话或关闭终端窗口。

二、常用快捷键

58. Ctrl + C — 终止当前正在运行的前台命令。

59. Ctrl + D — 退出当前终端或结束标准输入（相当于输入 exit）。

60. Ctrl + Z — 将当前前台进程挂起（暂停）并放入后台。

61. Ctrl + L — 清空终端屏幕（效果同 clear 命令）。

62. Ctrl + A — 光标快速跳转到命令行最开头。

63. Ctrl + E — 光标快速跳转到命令行最末尾。

64. Ctrl + U — 删除从光标位置到行首的所有字符。

65. Ctrl + K — 删除从光标位置到行尾的所有字符。

66. Ctrl + W — 删除光标前的一个单词。

67. Ctrl + Y — 粘贴刚才用 Ctrl+U、Ctrl+K 或 Ctrl+W 删除的内容。

68. Ctrl + R — 反向搜索历史命令，输入关键词即可匹配。

69. Ctrl + G — 退出历史命令搜索模式。

70. Ctrl + P — 查看上一条执行过的命令（效果等同于按上箭头键）。

71. Ctrl + N — 查看下一条执行过的命令（等同于按下箭头键）。

72. Ctrl + B — 光标向左移动一个字符（等同于左箭头键）。

73. Ctrl + F — 光标向右移动一个字符（等同于右箭头键）。

74. Ctrl + H — 删除光标前的一个字符（等同于退格键 Backspace）。

75. Ctrl + D（在命令行无字符时） — 退出终端。

76. Tab 键 — 自动补全命令、文件名或路径。

77. Tab 两次 — 显示所有可用的补全选项。

78. 上箭头 / 下箭头 — 浏览历史命令。

79. !! — 重复执行上一条命令。

80. !关键词 — 执行最近一条以“关键词”开头的命令。

81. Ctrl + Shift + C — 在终端中复制选中的文本（部分终端支持）。

82. Ctrl + Shift + V — 在终端中粘贴文本（部分终端支持）。

83. Ctrl + S — 暂停终端输出（阻止新内容滚动显示）。

84. Ctrl + Q — 恢复被 Ctrl+S 暂停的终端输出。



8月24-25日学习笔记
================================

一、项目背景
-----------
学习嵌入式开发，需要搭建完整的开发环境，包括：
- Windows端：VMware虚拟机、Keil MDK开发环境
- Ubuntu端：Linux开发环境、网络配置、远程开发

二、虚拟机环境搭建
-----------------
1. 安装VMware Workstation 16 Pro

2. 导入Ubuntu 20.04虚拟机镜像

3. 常见问题及解决
   问题1：虚拟机无法启动，提示"请求的电源操作已在执行中"
   解决：
   - .wmx文件virtualHW.version = "12" 改成 “18”

   问题2：虚拟机启动失败，报错"ULM: Failed to set up partition"
   原因：Windows Hyper-V与VMware冲突
   解决：
   - 以管理员身份打开CMD，执行：
     bcdedit /set hypervisorlaunchtype off
   - 重启电脑后VMware即可正常运行

三、Ubuntu系统配置
------------------
1. 虚拟机网络配置（桥接模式）
   - 打开虚拟网络编辑器，添加VMnet0桥接网络
   - 桥接到主机正在使用的物理网卡（WiFi或以太网）
   - 虚拟机网络适配器设为"桥接模式"，勾选"复制物理网络连接状态"

2. 常见网络问题
   问题：Ubuntu无法联网，ping报"Network is unreachable"
   解决：
   - 点击恢复网络设置按钮后，重启Ubuntu，重新联网
  
3. SSH远程连接
   - Ubuntu端：安装并启动SSH服务
     sudo apt install openssh-server -y
     sudo systemctl start ssh
   - Windows端：用 ssh harmony@虚拟机IP 连接

四、Keil MDK开发环境
--------------------
1. 安装MDK525

2. 激活（使用学校提供的注册机）

3. 芯片包安装

4. 新建STM32工程

5. ST-LINK调试器配置
   问题：Keil报"no ST-LINK detected"
   解决：
   - 安装ST-LINK驱动
   - 设备管理器中手动更新驱动，指向stlink.inf文件
   - Keil中配置：Debug -> Use ST-Link Debugger -> Port选SW
   - Flash Download -> Add STM32F10x Medium-density Flash

6. 下载程序

五、VSCode远程开发
------------------
1. 安装Remote-SSH插件
2. 连接Ubuntu：Ctrl+Shift+P -> Remote-SSH: Connect to Host... -> harmony@192.168.119.128
3. 常见问题及解决
   问题：VSCode连接卡住，长时间显示"正在初始化VSCode服务器"
  解决：
   - SSH进入Ubuntu，删除缓存：rm -rf ~/.vscode-server
   - 重新连接，VSCode会自动重新下载服务器组件
