## 二、OLED 显示原理

### 2.1 OLED 技术概述

OLED（Organic Light Emitting Display，有机发光显示器）被称为第三代显示技术。相比传统显示技术，OLED 具有以下特点：

- 更轻薄，能耗更低
- 亮度高，发光效率好
- 可显示纯黑色（像素独立发光）
- 可弯曲，适用于曲屏手机和电视

### 2.2 硬件连接

本实验使用的 OLED 屏型号为 **OG-2832TSWFG02**（0.91寸，128×32 分辨率），通过 I2C 总线与 Hi3861 开发板连接。

## 三、I2C 总线通信原理

### 3.1 什么是 I2C 总线

I2C（Inter-Integrated Circuit）总线是 Philips 公司开发的两线式串行总线，用于连接微控制器及其外围设备，属于半双工通信方式。

I2C 总线包含两根信号线：

| 信号线 | 功能 |
|--------|------|
| SDA（Serial Data Line） | 双向数据线 |
| SCL（Serial Clock Line） | 时钟线（由主控器件产生） |

所有 I2C 设备的 SDA 和 SCL 引脚分别并联到总线的 SDA 和 SCL 上，每个设备都有唯一的地址。

### 3.2 I2C 总线特点

- **简单性**：接口直接在线路上，占用空间小，减少电路板空间和芯片管脚数量，降低互联成本。
- **传输距离**：总线长度可达 25 英尺。
- **传输速率**：最大传输速率为 10Kbps，最多支持 40 个组件。
- **多主控支持**：支持多主控模式，任何能发送和接收的设备都可成为主总线，但同一时间只能有一个主控。

### 3.3 I2C 通信基本流程

I2C 通信包含三个关键阶段：

1. **起始信号**：SCL 为高电平时，SDA 从高电平跳变到低电平。
2. **数据传输**：数据按位传输，SCL 为高电平时 SDA 上的数据有效。
3. **停止信号**：SCL 为高电平时，SDA 从低电平跳变到高电平。

## 四、I2C 相关 API

鸿蒙系统中 I2C 操作的主要 API 如下：

### 4.1 I2cInit

| 项目 | 说明 |
|------|------|
| 功能 | 用指定的频率初始化 I2C 设备 |
| 函数定义 | `unsigned int I2cInit(WifiIotI2cIdx id, unsigned int baudrate)` |
| 参数 | `id`: I2C 设备 ID<br>`baudrate`: I2C 通信频率 |
| 返回值 | 错误码 |

### 4.2 I2cWrite

| 项目 | 说明 |
|------|------|
| 功能 | 向 I2C 设备写入数据 |
| 函数定义 | `unsigned int I2cWrite(WifiIotI2cIdx id, unsigned short deviceAddr, const WifiIotI2cData *i2cData)` |
| 参数 | `id`: I2C 设备 ID<br>`deviceAddr`: I2C 设备地址<br>`i2cData`: 指向待写入数据的指针 |
| 返回值 | 错误码 |

### 4.3 I2cRead

| 项目 | 说明 |
|------|------|
| 功能 | 从 I2C 设备读取数据 |
| 函数定义 | `unsigned int I2cRead(WifiIotI2cIdx id, unsigned short deviceAddr, const WifiIotI2cData *i2cData)` |
| 参数 | `id`: I2C 设备 ID<br>`deviceAddr`: I2C 设备地址<br>`i2cData`: 指向存放读取数据缓冲区的指针 |
| 返回值 | 错误码 |

### 4.4 I2cSetBaudrate

| 项目 | 说明 |
|------|------|
| 功能 | 设置 I2C 通信频率 |
| 函数定义 | `unsigned int I2cSetBaudrate(WifiIotI2cIdx id, unsigned int baudrate)` |
| 参数 | `id`: I2C 设备 ID<br>`baudrate`: I2C 通信频率 |
| 返回值 | 错误码 |

## 五、实验总结

I2C 总线通过两根信号线实现多设备连接，在嵌入式系统设计中具有重要意义。掌握 I2C 的基本原理和 API 使用方法，是驱动 OLED、温湿度传感器等 I2C 接口外设的基础。后续将在此基础上完成 OLED 屏幕的驱动实验，实现字符和图形显示功能。
