# 2026年9月2日 嵌入式系统开发实验笔记

## 一、实验概览

今日主要围绕 Hi3861 开发板的两个无线通信实验展开：蓝牙遥控小车与 Wi-Fi 热点连接。两个实验分别涉及短距离无线控制和 Wi-Fi 网络接入，为后续物联网应用开发奠定基础。

---

## 二、蓝牙遥控小车实验

### 2.1 实验目的

掌握蓝牙模块与 Hi3861 的串口通信方法，实现通过手机蓝牙遥控小车运动。

### 2.2 实验原理

蓝牙通讯是一种短距离、低功耗的无线通信方式，适用于频繁传输数据的场景。本实验中：
- 手机端通过蓝牙 APP 发送控制指令
- Hi3861 通过蓝牙模块接收数据
- 经串口解析后控制小车电机运动

### 2.3 硬件连接

| 蓝牙模块引脚 | Hi3861 引脚 |
|-------------|-------------|
| VCC | 3.3V / 5V |
| GND | GND |
| TX | RX（串口接收） |
| RX | TX（串口发送） |

### 2.4 关键技术点

1. 蓝牙模块的串口通信配置（波特率、数据格式）
2. 串口中断接收与数据解析
3. 控制指令与电机动作的映射

---

## 三、OpenHarmony Wi-Fi 热点连接实验

### 3.1 实验目的

掌握 OpenHarmony 系统中 Wi-Fi 相关 API 的使用方法，实现 Hi3861 开发板连接指定 Wi-Fi 热点。

### 3.2 实验原理

Hi3861 开发板内置 Wi-Fi 模块，通过 OpenHarmony 系统提供的 Wi-Fi API，可以实现：
- 扫描可用网络
- 连接指定热点
- 获取网络状态

### 3.3 常用 Wi-Fi API

| API | 功能 |
|-----|------|
| `WifiScan` | 扫描 Wi-Fi 热点列表 |
| `WifiConnect` | 连接指定热点 |
| `WifiDisconnect` | 断开连接 |
| `WifiGetConnectedInfo` | 获取当前连接信息 |
| `WifiGetScanList` | 获取扫描结果列表 |

### 3.4 连接流程

1. 初始化 Wi-Fi 模块
2. 扫描可用网络
3. 选择目标热点
4. 配置 SSID 和密码
5. 发起连接请求
6. 等待连接成功
7. 获取 IP 地址并验证网络连通性

---

## 四、相关 API 使用说明

### 4.1 蓝牙串口通信

| 函数 | 作用 |
|------|------|
| `UartInit()` | 初始化串口（波特率、数据位、停止位） |
| `UartWrite()` | 发送数据 |
| `UartRead()` | 读取数据 |
| `UartSetCallback()` | 设置接收回调函数 |

### 4.2 Wi-Fi 连接 API

| 函数 | 作用 |
|------|------|
| `WifiInit()` | Wi-Fi 模块初始化 |
| `WifiScan()` | 开始扫描热点 |
| `WifiGetScanInfo()` | 获取扫描到的热点信息 |
| `WifiAddConfig()` | 添加网络配置 |
| `WifiConnect()` | 连接热点 |
| `WifiGetConnectInfo()` | 获取连接状态 |

---

## 五、实验小结

1. 蓝牙通信适合短距离、低功耗的无线控制场景，可通过手机 APP 实现人机交互。
2. Wi-Fi 通信适用于需要接入互联网的物联网设备，可实现远程监控与控制。
3. 两种通信方式都需要关注数据传输的可靠性、稳定性与实时性。

---

## 六、注意事项

- 蓝牙模块与 Hi3861 的串口波特率必须一致
- Wi-Fi 连接时需正确配置 SSID 和密码
- 调试过程中可通过串口打印查看连接状态和错误信息
- 蓝牙遥控 APP 的指令格式需与 Hi3861 解析逻辑匹配

---

**备注：** 今日两个实验均为通信类实验，后续可将蓝牙遥控与 Wi-Fi 功能结合，实现更复杂的物联网应用场景。
