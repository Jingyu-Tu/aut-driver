# Linux 常用命令与开发环境搭建笔记

> 学习时间：2024年8月24-25日


## 📁 一、常用命令（按功能分类）

### 📍 目录与文件操作

| 命令 | 说明 |
| :--- | :--- |
| `pwd` | 显示当前所在目录的绝对路径 |
| `ls` | 列出当前目录下的文件和文件夹 |
| `ls -l` | 以详细列表形式显示文件权限、大小、修改时间等 |
| `ls -a` | 显示所有文件，包括以点开头的隐藏文件 |
| `cd 目录路径` | 切换到指定目录 |
| `cd ..` | 返回上一级目录 |
| `cd ~` | 切换到当前用户的主目录 |
| `cd /` | 切换到系统根目录 |
| `mkdir 目录名` | 在当前目录下创建新文件夹 |
| `mkdir -p 父目录/子目录` | 递归创建多级目录 |
| `rmdir 目录名` | 删除空目录 |
| `rm 文件名` | 删除文件 |
| `rm -r 目录名` | 递归删除目录及其所有内容 |
| `rm -f 文件名` | 强制删除文件，不提示确认 |
| `cp 源文件 目标路径` | 复制文件到指定位置 |
| `cp -r 源目录 目标路径` | 递归复制整个目录 |
| `mv 源 目标` | 移动文件或目录，也可用于重命名 |
| `touch 文件名` | 创建空文件，或更新已有文件的时间戳 |

### 📄 文件查看与搜索

| 命令 | 说明 |
| :--- | :--- |
| `cat 文件名` | 在终端中显示文件全部内容 |
| `less 文件名` | 分页查看大文件内容，按 `q` 退出 |
| `head -n 行数 文件名` | 查看文件开头若干行 |
| `tail -n 行数 文件名` | 查看文件末尾若干行 |
| `tail -f 文件名` | 动态跟踪文件新增内容（实时日志） |
| `grep "关键词" 文件名` | 在文件中搜索包含关键词的行 |
| `grep -r "关键词" 目录` | 在目录下所有文件中递归搜索 |
| `find 目录 -name "文件名模式"` | 按名称查找文件 |
| `find 目录 -type f -size +10M` | 查找大于 10MB 的普通文件 |

### ✏️ 文本与输出

| 命令 | 说明 |
| :--- | :--- |
| `echo "文本"` | 在终端输出文本，常用于脚本 |
| `echo "文本" > 文件` | 将文本写入文件（覆盖原内容） |
| `echo "文本" >> 文件` | 将文本追加到文件末尾 |

### 🔧 权限管理

| 命令 | 说明 |
| :--- | :--- |
| `chmod 权限 文件` | 修改文件或目录的读写执行权限 |
| `chown 用户:组 文件` | 修改文件或目录的所有者和所属组 |

### ⚙️ 进程管理

| 命令 | 说明 |
| :--- | :--- |
| `ps` | 显示当前终端运行的进程 |
| `ps aux` | 显示系统所有进程的详细信息 |
| `kill 进程ID` | 终止指定进程 |
| `kill -9 进程ID` | 强制终止进程 |
| `top` | 实时查看系统资源占用和进程状态 |
| `htop` | 更直观的交互式进程查看器（需安装） |

### 💾 磁盘与系统信息

| 命令 | 说明 |
| :--- | :--- |
| `df -h` | 查看磁盘分区使用情况（人类可读格式） |
| `du -sh 目录` | 查看目录总大小 |
| `du -h --max-depth=1` | 查看当前目录下各子目录大小 |
| `free -h` | 查看内存和交换分区使用情况 |
| `uname -a` | 查看系统内核版本和架构信息 |
| `whoami` | 显示当前登录用户名 |
| `hostname` | 显示主机名 |

### 🌐 网络相关

| 命令 | 说明 |
| :--- | :--- |
| `ifconfig` | 查看网络接口配置（需安装 net-tools） |
| `ip a` | 查看网络接口和 IP 地址 |
| `ping 域名或IP` | 测试网络连通性 |
| `wget 链接` | 下载网络文件 |
| `curl 链接` | 发送 HTTP 请求并获取内容 |

### 📦 压缩与解压

| 命令 | 说明 |
| :--- | :--- |
| `tar -czvf 压缩包名.tar.gz 目录` | 打包并压缩为 tar.gz 格式 |
| `tar -xzvf 压缩包名.tar.gz` | 解压 tar.gz 文件 |
| `zip -r 压缩包名.zip 目录` | 压缩为 zip 格式 |
| `unzip 压缩包名.zip` | 解压 zip 文件 |

### 🧹 其他常用命令

| 命令 | 说明 |
| :--- | :--- |
| `history` | 查看当前用户执行过的命令历史 |
| `clear` | 清空终端屏幕内容 |
| `exit` | 退出当前终端会话或关闭终端窗口 |


## ⌨️ 二、常用快捷键

### 进程与屏幕控制

| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + C` | 终止当前正在运行的前台命令 |
| `Ctrl + D` | 退出当前终端或结束标准输入（相当于输入 `exit`） |
| `Ctrl + Z` | 将当前前台进程挂起（暂停）并放入后台 |
| `Ctrl + L` | 清空终端屏幕（效果同 `clear` 命令） |
| `Ctrl + S` | 暂停终端输出（阻止新内容滚动显示） |
| `Ctrl + Q` | 恢复被 `Ctrl+S` 暂停的终端输出 |

### 光标移动与编辑

| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + A` | 光标快速跳转到命令行最开头 |
| `Ctrl + E` | 光标快速跳转到命令行最末尾 |
| `Ctrl + B` | 光标向左移动一个字符（等同于左箭头键） |
| `Ctrl + F` | 光标向右移动一个字符（等同于右箭头键） |
| `Ctrl + H` | 删除光标前的一个字符（等同于退格键 Backspace） |
| `Ctrl + U` | 删除从光标位置到行首的所有字符 |
| `Ctrl + K` | 删除从光标位置到行尾的所有字符 |
| `Ctrl + W` | 删除光标前的一个单词 |
| `Ctrl + Y` | 粘贴刚才用 `Ctrl+U`、`Ctrl+K` 或 `Ctrl+W` 删除的内容 |

### 历史命令与补全

| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + R` | 反向搜索历史命令，输入关键词即可匹配 |
| `Ctrl + G` | 退出历史命令搜索模式 |
| `Ctrl + P` | 查看上一条执行过的命令（等同于上箭头键） |
| `Ctrl + N` | 查看下一条执行过的命令（等同于下箭头键） |
| `上箭头 / 下箭头` | 浏览历史命令 |
| `Tab 键` | 自动补全命令、文件名或路径 |
| `Tab 两次` | 显示所有可用的补全选项 |
| `!!` | 重复执行上一条命令 |
| `!关键词` | 执行最近一条以"关键词"开头的命令 |

### 复制粘贴

| 快捷键 | 说明 |
| :--- | :--- |
| `Ctrl + Shift + C` | 在终端中复制选中的文本 |
| `Ctrl + Shift + V` | 在终端中粘贴文本 |
