## 三、STM32 PWM 驱动电机实验

### 3.1 PWM 基本原理

PWM（脉冲宽度调制）是一种利用数字信号控制模拟电路的技术，广泛应用于电机调速、LED 调光等场景。

三个关键参数：

- **频率**：1 秒内信号周期的次数，单位 Hz
- **周期**：一个完整脉冲的时间长度
- **占空比**：高电平时间占整个周期的比例，范围 0%~100%

输出信号的平均电压 = 占空比 × 输入电压。

### 3.2 STM32 定时器配置

以 TIM4 为例，输出两路 PWM 信号控制左右轮电机：

- 重载值 ARR = 7199
- 预分频系数 PSC = 9
- PWM 频率 = 72MHz / (PSC+1) / (ARR+1) = 1000Hz

配置流程：

1. 使能 TIM4 和 GPIOB 时钟
2. 配置 GPIOB 的 Pin6、Pin7 为复用推挽输出
3. 初始化 TIM4 定时器基址
4. 配置 PWM 模式、输出通道、极性
5. 使能预装载和定时器

### 3.3 电机控制函数

通过 `Set_Pwm(moto1, moto2)` 函数控制两个电机：

- 正负值控制正反转
- 绝对值控制转速
- 实现差速转向

## 四、Hi3861 舵机控制与互斥锁实验

### 4.1 舵机驱动原理

舵机 SG90 通过 GPIO2 接收控制信号：

- 周期：20ms 脉冲
- 0°：高电平 500μs
- 90°：高电平 1500μs
- 180°：高电平 2500μs

通过 `hi_udelay()` 实现微秒级延时，控制高电平宽度，从而控制舵机角度。

### 4.2 互斥锁概念

互斥锁（Mutex）用于解决多任务共享资源的竞争问题：

- **作用**：确保同一时刻只有一个任务访问共享资源
- **机制**：任务在访问资源前获取锁，使用后释放锁
- **阻塞**：若锁被占用，其他任务需等待

### 4.3 互斥锁 API

| API | 功能 |
|-----|------|
| `osMutexNew(NULL)` | 创建互斥锁 |
| `osMutexAcquire(id, timeout)` | 获取锁 |
| `osMutexRelease(id)` | 释放锁 |
| `osMutexDelete(id)` | 删除锁 |

### 4.4 任务设计

创建三个线程：

- **thread1（优先级 26）**：获取锁 → 舵机转 90° → 延时 5s → 释放锁
- **thread2（优先级 25）**：中优先级，不获取锁，仅打印状态
- **thread3（优先级 24）**：获取锁 → 舵机转 180° → 延时 3s → 释放锁
