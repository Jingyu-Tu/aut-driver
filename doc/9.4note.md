# 2026年9月4日 嵌入式系统开发实验笔记

## 一、实验概览

今日实验主要围绕 Hi3861 开发板的小车循迹功能展开。通过三路 TCRT5000 红外传感器检测黑白胶带铺设的轨道，实现小车沿黑色胶带自动循迹行驶，并处理弯道、分叉路口等复杂路况。实验涉及传感器信号采集、滤波去抖、状态机控制与电机 PWM 调速等内容。

---

## 二、循迹系统硬件架构

### 2.1 传感器选型与引脚分配

| 传感器 | 功能 | Hi3861 引脚 |
|--------|------|-------------|
| 左路红外（TCRT5000） | 检测左侧轨道边界 | GPIO_12 |
| 中路红外（TCRT5000） | 检测中心黑线 | GPIO_13 |
| 右路红外（TCRT5000） | 检测右侧轨道边界 | GPIO_14 |

### 2.2 轨道物理特性

| 参数 | 规格 |
|------|------|
| 轨道类型 | 黑色胶带铺设（中心黑线 + 两侧白线辅助边界） |
| 黑线宽度 | 约 1.5~2.0 cm |
| 传感器离地高度 | 1~2 cm |
| 三路传感器间距 | 1.5~2.0 cm |

### 2.3 电机通信接口

Hi3861 通过 UART2（GPIO_11/GPIO_12）与 STM32 通信，波特率 115200，发送 6 字节控制帧：

| 字节 | 内容 | 说明 |
|------|------|------|
| Byte 0 | `0xFC` | 帧头 |
| Byte 1 | 方向 A | 左轮方向（0 正转 / 1 反转） |
| Byte 2 | 速度 A | 左轮速度（0~150） |
| Byte 3 | 方向 B | 右轮方向（0 正转 / 1 反转） |
| Byte 4 | 速度 B | 右轮速度（0~150） |
| Byte 5 | `0xFD` | 帧尾 |

## 三、传感器信号处理

### 3.1 红外传感器工作原理

TCRT5000 通过红外发射管照射地面，接收管检测反射光强度：

| 地面颜色 | 反射率 | 传感器逻辑值 |
|----------|--------|-------------|
| 白色（胶带/地面） | 高 | 0（低电平） |
| 黑色（胶带/轨道线） | 低 | 1（高电平） |

> **注**：具体极性与传感器模块电路设计有关，需实际测试确认。本实验中设定 `BLACK_VALUE = 1`，`WHITE_VALUE = 0`。

### 3.2 信号去抖动处理

由于传感器输出存在噪声，采用连续采样确认机制：

```c

} else {
    stable_counter = 0;
    last_dir = dir;
}
if (stable_counter < 2) {

## 四、循迹控制算法

### 4.1 方向状态定义

```c
typedef enum {
    DIR_FORWARD,   // 直行
    DIR_LEFT,      // 左转
    DIR_RIGHT,     // 右转
    DIR_STOP       // 停止（脱线）
} CarDirection;

### 4.2 循迹判断逻辑

核心原则：**保证中间传感器始终对准黑线**。

| 左传感器 | 中传感器 | 右传感器 | 判断结果 | 执行动作 |
|---------|---------|---------|---------|---------|
| 白 | 黑 | 白 | 完美居中 | 直行 |
| 黑 | 黑 | 白 | 左偏 | 左转修正 |
| 白 | 黑 | 黑 | 右偏 | 右转修正 |
| 黑 | 白 | 白 | 黑线在左 | 左转找线 |
| 白 | 白 | 黑 | 黑线在右 | 右转找线 |
| 白 | 白 | 白 | 完全脱线 | 停止 |
| 黑 | 黑 | 黑 | 十字/交叉口 | 直行通过 |

### 4.3 速度参数配置

| 参数 | 值 | 说明 |
|------|-----|------|
| `SPEED_BASE` | 40~70 | 直行基础速度（可调） |
| `SPEED_TURN` | 28~40 | 转向速度差 |

速度调整原则：
- 直道可提速（SPEED_BASE = 70）
- 弯道需减速或保持中等速度（SPEED_BASE = 40~50）
- 转向速度差越大，转弯越急

### 4.4 脱线恢复策略

当所有传感器检测为白（全白脱线）时，进入脱线恢复流程：

```c
lost_counter++;
if (lost_counter < 30) {
    car_left();   // 原地左转寻找黑线
} else {
    car_stop();   // 长时间未找到黑线，停车
}

### 5.2 动作封装

| 动作 | 左轮 | 右轮 | 效果 |
|------|------|------|------|
| `car_forward()` | +SPEED_BASE | +SPEED_BASE | 直线前进 |
| `car_left()` | -SPEED_TURN | +SPEED_TURN | 原地左转 |
| `car_right()` | +SPEED_TURN | -SPEED_TURN | 原地右转 |
| `car_stop()` | 0 | 0 | 停止 |

### 5.3 主循环控制流程
1. 读取三路传感器状态
2. 去抖动滤波（连续 2 次相同状态）
3. 根据传感器状态判断方向
4. 执行对应动作
5. 延时 20ms 后继续循环
## 六、弯道与分叉路口处理

### 6.1 弯道识别

弯道时，左右传感器中至少有一侧会检测到黑线：

| 弯道方向 | 传感器状态 |
|----------|-----------|
| 左弯 | 左传感器先检测到黑线 |
| 右弯 | 右传感器先检测到黑线 |
| 急弯 | 中间传感器变白，一侧传感器变黑 |

### 6.2 分叉路口处理

对于斜向左分叉路口，采用逐步转向策略：
1. 检测到偏左信号
2. 先执行小角度左转
3. 持续偏左超过阈值后，加大转向角度

## 八、今日知识点总结

| 知识点 | 内容 |
|--------|------|
| 红外循迹原理 | TCRT5000 利用不同颜色反射率差异检测黑线 |
| 三路传感器布局 | 左/中/右并排，中间对准黑线，两侧检测边界 |
| 信号去抖动 | 连续多次采样确认，避免噪声误触发 |
| 状态机控制 | 根据传感器组合判断方向，执行对应动作 |
| 速度与稳定性 | 速度越快，转向响应要求越高，需平衡 |
| 脱线恢复 | 通过原地旋转寻找黑线，超时后停车 |

## 九、实验小结

循迹小车的核心在于传感器的可靠检测与控制算法的实时响应。三路传感器相比两路传感器能够更准确地判断黑线位置，尤其在弯道和分叉路口时具有更好的鲁棒性。实际调试中，传感器离地高度、轨道宽度、环境光照等因素都会影响检测效果，需要通过串口打印确认传感器极性，并根据轨道情况调整速度参数和转向灵敏度。
